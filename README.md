# Machine Learning Assignment 2

## Problem Statement

Build and deploy an interactive Streamlit application that compares multiple classification models on a single public dataset, reports standard evaluation metrics, and displays the outcome on uploaded test data.

## Dataset Description

This project uses the UCI Spambase dataset.

- Task: binary classification
- Instances: 4,601
- Features: 57 numeric predictors
- Target: `is_spam`

Why this dataset:

- It satisfies the assignment constraints of at least 12 features and 500 rows.
- It is fully numeric, so all required models can be trained and deployed cleanly.
- It works well with the required evaluation metrics, including AUC and MCC.
